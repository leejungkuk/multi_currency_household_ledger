# PRD: 환율 가계부 SaaS (woni)

## 목표
해외 체류·여행·직구 사용자가 외화 지출을 당일 환율(tts)로 자동 환산해 기록하고, 월별로 원화 기준 수입·지출을 추적하는 멀티테넌트 가계부 SaaS.

## 사용자
- **P1 단기 여행자**: 1~2주 해외여행, 그날 외화 지출을 빠르게 기록하고 "오늘 원화로 얼마?" 확인
- **P2 장기 체류자**(유학/주재원): 외화 생활비 + 원화 수입을 월별로 추적
- **P3 해외 직구족**: 국내 거주, 가끔 외화 결제건을 원화 환산해 기록
- **P4 국내 일반 사용자**: KRW only, 단순 수입/지출 가계부

네 페르소나 공통 전제: **가입 없이 바로 쓰기 시작**하고(게스트), 원할 때 계정을 연결해 다기기·기기변경 백업을 얻는다.

## 핵심 기능
1. 신원: **게스트-퍼스트**. Supabase **익명 로그인**으로 게스트도 서버 백업 신원을 갖고(첫 입력 시 지연 발급), "가입"은 새 계정 생성이 아니라 **같은 UUID에 소셜/이메일을 연결하는 업그레이드**다 — 신원 교체·데이터 이관이 없다. 백엔드는 익명 JWT와 영구 JWT를 구분하지 않는다(`member_id` = JWT subject UUID).
2. 거래 입력·수정·삭제: 외화/원화 지출·수입 기록(외화는 tts 기준 KRW 환산값 저장; 금액 8자리, 카테고리·자산 필수, 메모 선택). 수정/삭제는 등록 폼 재사용, **외화 수정 시 환율 재해석**(member_id+IDOR)
3. 홈/메인: 선택 월의 `income`/`expense`/`total(순액)` + 최근 내역(`(date desc, id desc)` 정렬, 서버 캡)
4. 월별 리포트: 통화별(수입·지출 분리)·카테고리별 소계
5. 환율 자동화: 매일 11:05 KST 수출입은행 tts 수집 + **보정창(최근 N일) 내 "적용 가능한 최신 환율보다 오래된" 외화 거래 재계산**(멱등·수렴). 영업일 수집 실패 시 당일 인트라데이 재시도로 회수. 앱이 오프라인에서도 환산할 수 있도록 과거 구간을 내려주는 조회(`/exchange-rates/range`·`/snapshot`) 제공
6. 설정: 기준 통화(KRW)·환율 마지막 업데이트 상태 확인
7. **로컬-퍼스트 동기화**: 앱은 로컬에 먼저 쓰고 서버로 밀어 올린다 — 단건 `sync`(`client_entry_id` 멱등키)·일괄 `import`(payload 해시 선행조건, 최대 1000건)·증분 `changes`·신규 기기 복원 `restore`(뒤 둘은 키셋 커서, 페이지 ≤500)
8. **계정 삭제(탈퇴)**: `DELETE /api/v1/members/me` 하나로 `auth.users` 행 삭제 + FK CASCADE, Apple 로그인 연결 해제는 best-effort
9. **내 데이터 삭제(purge)**: `DELETE /api/v1/ledgers` — 계정은 남기고 그 회원의 **거래 + 커스텀 카테고리(활성·비활성 모두)** 를 한 트랜잭션에서 hard delete 한다(`fk_ledger_category`에 cascade가 없어 거래→카테고리 순). 시스템 공용 카탈로그·자산·환율은 불변

## MVP 제외 사항
- 달력 뷰 — fast-follow (※ 거래 수정/삭제(U/D)는 2026-06-13 개정으로 **MVP 포함**으로 이동)
- 커스텀 자산, 프로필/회원 테이블(JWT UUID 직접 사용)
- RLS, 캐시(Caffeine/Redis), Sentry(에러 트래킹), ShedLock
- 익명 데이터와 **기존 계정 데이터의 병합** — 연결 충돌 시 로컬 익명 데이터를 지우지 않는 비파괴 보존까지만
- (해제됨 2026-08-23) ~~버려진 익명 계정 cleanup~~ — `service_role` key가 필요하다는 전제가 틀렸다. 백엔드가 기존 Postgres 연결로 `auth.users`를 직접 지우므로 **365일 미활동 익명 계정을 주기 배치(매일 04:00 KST)로 물리 삭제**한다(ADR-011 개정). 첫 배포는 관측 전용 모드(`enabled=false`)
- 반복/할부, 예산·리포트 고도화, 결제수단별 잔액 추적

## 디자인
- 4화면(홈 · 입력 · 월별 리포트 · 설정) 중심, 입력 마찰 최소화(카테고리·자산 1탭 선택, 메모 선택)
- 외화 입력 시 즉시 "오늘 환율 / 원화 환산값" 피드백
- 지원 통화: 13종 — KRW · USD · EUR · JPY · CNY · GBP · THB · HKD · SGD · IDR · MYR · AUD · NZD. 기준 통화 KRW 고정(v1), 다국어 표시명 KO/EN
